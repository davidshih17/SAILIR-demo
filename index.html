SAILIR

Learning to unscramble Feynman loop integrals

Laporta solves one large linear system, and memory sets the limit. SAILIR reduces an integral one IBP identity at a time, with a transformer choosing each identity. It never builds a global linear system.

Paper: arXiv:2604.05034Code and trained model
